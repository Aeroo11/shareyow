# Retrospektif sprint

Tiga kalimat per sprint. Tidak lebih.

1. **Apa yang lebih lambat dari perkiraan** — dan angkanya, bukan perasaannya.
2. **Kenapa** — penyebabnya, bukan gejalanya.
3. **Apa yang diubah minggu depan** — satu perubahan konkret, bukan niat baik.

Retro yang berkembang jadi esai tidak akan ditulis lagi minggu berikutnya. Batas
tiga kalimat itu yang membuatnya bertahan sampai sprint terakhir.
